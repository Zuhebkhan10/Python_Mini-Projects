Python Spell Checker

A beginner-friendly spell checker built from scratch using Python and the `pyspellchecker` library.

This mini project demonstrates how to build a simple **command-line spell checker** in Python. It reads text input from the user, identifies misspelled words, suggests corrections, and outputs the corrected sentence. It's ideal for Python beginners who want hands-on experience with classes, loops, string manipulation, and third-party libraries.
