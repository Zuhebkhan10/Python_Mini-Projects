Phone Number Location Finder (GUI)

A simple and user-friendly desktop application built with Python and Tkinter that extracts basic information from a phone number.

The application displays:

Country

Carrier name

Timezone

This project is useful for beginners who want to learn GUI development, Python libraries, and mini data tools.

Features:

Graphical User Interface using Tkinter

Phone number parsing with phonenumbers

Shows telecom region and carrier

Error handling for invalid inputs

Clean and simple layout

Technologies Used:

Python

Tkinter

phonenumbers
